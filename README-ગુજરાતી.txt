APK અને EXE બનાવવાની રીત (GitHub પર, ફ્રી):
1) github.com પર નવી private repository બનાવો.
2) આ ફોલ્ડરની બધી ફાઇલો (.github ફોલ્ડર સાથે) અપલોડ કરો.
3) Actions ટેબ ખોલો:
   - "Build PROTOCOL SAKHA APK" -> Run workflow  -> PROTOCOL-SAKHA.apk
   - "Build PROTOCOL SAKHA EXE" -> Run workflow  -> PROTOCOL-SAKHA.exe
4) 5-8 મિનિટ પછી Artifacts માંથી ફાઇલ ડાઉનલોડ કરો.

નવું: રજા સુવિધા
- રજા / અનુપલબ્ધ મેનૂમાં "તારીખ થી - તારીખ સુધી" રજા ઉમેરાય છે, રજાનો પ્રકાર અને કુલ દિવસ સચવાય છે.
- વર્ષ મુજબ બધા કર્મચારીની રજાનો દિવસ સારાંશ (CL/મેડિકલ/EL/HPL/LWP/અન્ય) દેખાય છે.
- કર્મચારી પ્રમાણે યાદી જોઈ શકાય છે; કર્મચારી ઇતિહાસમાં પણ દેખાય છે.
- રજાની તારીખોમાં કર્મચારી ડ્યુટી રોટેશનમાંથી આપમેળે બાકાત રહે છે.

મહત્વનું:
- protocol-sakha.keystore સાચવી રાખો (દરેક વખતે એ જ કીથી APK સાઇન થશે, એટલે જૂની APK ઉપર update થશે, ડેટા જળવાશે). APK uninstall ન કરવી.
- આઇકન: assets/icon.png ને તમારા 1024x1024 ફોટાથી બદલો.

નવું (કેલેન્ડર અને આઇકન):
- કેલેન્ડર કાલનિર્ણય જેવા લુકમાં: ડાબે વાર, દરેક તારીખ મોટા ગુજરાતી અંકમાં, ઉપર મહિનો-વર્ષ અને વિક્રમ સંવત.
- રંગ: રવિવાર ગુલાબી, બીજો/ચોથો શનિવાર આછો વાદળી, જાહેર રજા લીલી, મરજીયાત રજા પીળી.
- જાહેર રજા શનિ/રવિ ના દિવસે આવે તો ઘેરો લાલ, મરજીયાત રજા શનિ/રવિ ના દિવસે આવે તો નારંગી બેકગ્રાઉન્ડ.
- તારીખ ઉપર ટેપ કરો તો રજાનું નામ અને તે દિવસે રજા ઉપર રહેલા કર્મચારી દેખાય.
- એપ આઇકન: VVIP Protocol Team નો ફોટો (assets/icon*.png) - APK અને EXE બંનેમાં.
- રોટેશનમાં નામ બદલવા: ફાળવણી કાર્ડમાં નામ ઉપર ટેપ (🔁) -> નવું નામ પસંદ કરો. જૂનાને રજા મૂકવાનું ટિક હોય તો તેની રજા રજા-ઇતિહાસમાં (પ્રકાર સાથે) નોંધાય છે.
